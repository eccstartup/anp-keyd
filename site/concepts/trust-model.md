# 当前开发模式的安全边界

Linux 已有独立管理域的 M1 预览，数据面签名关闭；有限 grant 和受保护发行尚未实现。同 UID 的 Agent 可以访问
同一用户的文件和进程，0600/0700 不能隔离它们。程序 pin 只作辅助检查。

- v1 CLI 解锁口令经过 Unix socket；客户端尚无受保护的服务端互认。
- `/dev/tty` 防止密码进入 argv/stdin，但 Agent 能创建 PTY，不能据此证明人类批准。
- 软件信封需要口令和 device.secret；整套目录被复制后，持有口令者仍可解封。
- 硬件绑定保护解封材料；Ed25519 seed 解锁后进入 daemon 内存，不是硬件内签名。
- raw/challenge 仅供显式开发兼容；256 字节限制不能阻止 64 字节文档 proof。
- 本地审计链可检查不一致，但日志和锚一起替换时没有独立回滚检测。
- 默认构建不含 seed-export；开启特性后的本地 CLI 仍受同 UID 边界限制。

Linux 预览已包含独立 UID 主体、管理员互认和独立 socket；请求策略、grant 撤销和事务恢复仍在实施中。
